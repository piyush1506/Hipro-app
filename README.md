# Hipro-app

Hindustan Projects (HiBuild) - Construction, Engineering & Building Maintenance Services Web & Mobile Application.

## Features
- 12 Native Mobile App Screens (Splash, Onboarding, Home, Services, Detail, Date & Patch Upload, Work Estimation, UPI Payment, Confirmation, Bookings, Projects, Profile)
- Dynamic Patch Work Photo Upload & Custom Estimation Flow
- 100% Local Vector & High-Res Image Assets
- Built with React 18, Vite & Lucide Icons

## Getting Started
```bash
npm install
npm run dev
```
